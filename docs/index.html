OSMa-Bench++: Toward Open-Ended Benchmarking of Semantic Mapping for Manipulation with Prompt-Generated Synthetic Scenes

A manipulation-oriented extension of OSMa-Bench for evaluating open-vocabulary semantic maps under controlled synthetic conditions: clutter, small objects, support relations, containment, and lighting variation.

Paper Code Dataset summary

Motivation

Why manipulation-oriented semantic mapping needs a stronger benchmark

Existing open-vocabulary semantic mapping methods can detect objects and build scene-level representations, but downstream manipulation requires more than object names. A robot often needs reliable object counts, support relations, containment, relative placement, and small manipulable objects grounded in 3D space.

OSMa-Bench++ targets this gap by generating controlled indoor scenes from prompts and evaluating whether semantic maps preserve information that is relevant for mobile manipulation.

Pipeline

Prompt-grounded scene generation and evaluation

01

Prompt generation

LLM-generated indoor scene descriptions are filtered for diversity and manipulation relevance. Prompts emphasize furniture-anchored layouts, small objects, and explicit spatial relations.

02

SceneSmith synthesis

Selected prompts are converted into synthetic indoor scenes with furniture, manipulable objects, clutter, and challenging layouts.

03

Simulation export

Generated scenes are converted into a Habitat-compatible dataset and rendered through the HaDaGe simulation pipeline.

04

VQA evaluation

Semantic maps are evaluated with prompt-grounded visual questions covering object existence, relations, measurements, manipulation preconditions, and reachability.

Benchmark setup

Controlled synthetic testbed

40 generated scenes
4 lighting configurations
160 rendered trajectories
2 mapping methods evaluated

Lighting configurations

  • baseline — default rendering configuration
  • camera — camera-attached lighting
  • dynamic_lights — scene-level dynamic lights
  • no_lights — low-illumination stress condition

Preliminary findings

What the benchmark reveals

The evaluation highlights that current open-vocabulary scene graphs still preserve manipulation-critical structure only partially. Prompt-grounded measurements and object relations remain difficult, especially when scenes include clutter, small manipulable objects, and challenging spatial arrangements.

BBQ and ConceptGraphs show different robustness profiles: BBQ is often stronger on relation-oriented and manipuland settings, while ConceptGraphs can be more stable under dynamic lighting. Segmentation quality and graph-level VQA performance do not always improve together, which motivates evaluating both geometric and semantic properties of the map.
